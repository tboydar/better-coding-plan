# 東南亞 / 澳洲 / 巴西（SGD / AUS / BRL）

## 新加坡 / 馬來西亞（SGD）

- 無新加坡本地定價，全為美元價 + 匯率（SG 通常免 GST 部分場景或含 8–9%）
- **GitHub Copilot Pro $10** 是最便宜入門（1,500 credits + 無限補全，CP 高）
- **ChatGPT Plus $20**（含 Codex）＝ 一個價錢同時拿 ChatGPT + Codex，輕中度最划算
- **Copilot Pro+ 曾有資訊標 $70**（含 Claude Code/Codex 第三方代理 + $15 併額度）；以官網為準
- 綜合建議：
  - 輕度：Copilot Pro $10
  - 中度：ChatGPT Plus $20（捆綁價值最高）
  - 重度：Codex Pro / Claude Max

## 澳洲（AUS）

- 標價皆美元，實際支付加 **GST（10%）** + 匯率
- **GitHub Copilot**：Free / Pro $10 / Pro+ $39 / Power-user $100 / Business $19 / Enterprise $39
  - 2026-06-01 啟用次量計費（credits）；Pro 檔中 Grok 4.5、GPT-5.6 Luna、Kimi K3 每月 $15 上限
- **Cursor**：Hobby 免費 / Pro $20（年$16）/ Pro+ $60 / Ultra $200 / Teams $40（年$32）/ Enterprise 客製
- 注意：重度 Cursor 用戶實際帳單可能 >> 標價

## 巴西（BRL）🇧🇷

- 無巴西本地定價，以美元＋匯率（假設 $1≈R$5.5）換算，加上 IOF/稅後更高
- **GitHub Copilot**：Pro ≈R$55 / Pro+ ≈R$215 / Max ≈R$550 / Business ≈R$105 per user
- **Cursor**：Pro ≈R$110 / Pro+ ≈R$330 / Ultra ≈R$1,100
- **Claude**：Pro ≈R$110 / Max ≈R$550–1,100
- 巴西重點：美元計價對 BRL 持有者較貴；**重度 Cursor 使用者帳單可達 R$1,100–7,700/mo**，需嚴控用量
- 替代：中國方案（GLM/Kimi）或開金開源（Cline+Aider）較省
