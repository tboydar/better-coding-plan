## 關鍵資訊

1. **Cursor Start ₹649/mo**：印度限定方案，是全球市場中少有的「本地特價」，比美國 $20 Pro 便宜 60% 以上。這是「跨國比價」最重要的發現之一。

2. **美元價換算**：印度無獨立美元定價，需加稅與匯率（匯率波動 + 支付手續費），實際支付略高於美元標價。

3. **用量的隱藏成本**：分析指出**標價只佔實際成本 30–50%**——AI 編碼工具會把 60–70% 的 context 浪費在無關檔案上，導致 token 超耗。重度使用者需算實際 token 消耗，而非只看標價。

4. **中國方案可跨區**：火山方舟 Lite ¥40（≈₹480）、阿里百煉 ¥198（≈₹2,400）在印度可能可透過國際支付購買，但跨境支付/合規需自行評估。
