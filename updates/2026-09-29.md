1. **OpenCode Go $10** 與 **Command Code GOAT $10** 是 CP 王者（6–7x 值）
2. **Mistral Le Chat Pro $14.99** 含 $15 API 積分，歐洲便宜王、被低估
3. **Cursor India Start ₹649** 是全球唯一印度特價（比 $20 Pro 省 60%）
4. **GLM Coding Plan 2026-08 大漲 261%**，CP 大幅下滑（Pro ¥538）
5. **Google AI 台幣/日圓官方定價**：台 NT$165–6,500、日 ¥725–32,000，是台日最划算高階
6. **開源 BYOK（Cline/Aider/Roo + DeepSeek）** 是重度 DIY 最省方案
